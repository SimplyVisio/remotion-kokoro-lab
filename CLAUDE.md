## Claude Code

Las reglas del proyecto están en `AGENTS.md`, importado arriba. Las skills de Remotion están disponibles en `.claude/skills/` (enlace a `.agents/skills/`).

Carga la skill adecuada antes de tocar la composición:

- `/remotion-best-practices` para orientarte.
- `/remotion-markup` para React, animación y layout.
- `/remotion-captions` para subtítulos.
- `/remotion-render` para exportar.
- `/remotion-studio` para la preview.
